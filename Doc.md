Faceted Interfaces for Prompt Engineering: Enhancing the Usability of Generative AI Tools

Generative AI systems such as ChatGPT have become powerful tools for creating text, images, and other media. However, users frequently struggle to produce effective prompts, especially when they have a clear idea of what they want but lack a structured way to express it. This project explores the design and evaluation of faceted interfaces to support prompt engineering, drawing inspiration from successful paradigms in search refinement (e.g., faceted search in e-commerce) and task-based UIs (e.g., Khanmigo for teachers). The student will design, prototype, and evaluate a faceted interface that allows users to specify elements such as goal, style, tone, format, and length before submitting a prompt to a generative AI system. The project will explore how structured input options improve usability, reduce cognitive load, and help users achieve more predictable and satisfactory outcomes from generative AI.

Project Objectives:

1.Review of Existing Interfaces: Conduct a survey of current generative AI interfaces, focusing on how prompts are created and refined (e.g., free-text vs. structured inputs).

2.Interface Design: Design a faceted interface that allows users to specify key prompt parameters such as style, tone, format, and length.

3.Prototype Development: Implement a web-based prototype that integrates the faceted interface with a generative text API (e.g., OpenAI or Anthropic).

4.User Evaluation: Conduct a usability study comparing the faceted interface with a traditional free-text prompt interface, focusing on user satisfaction, task success, and perceived control.

5.Analysis and Recommendations: Analyze results and propose design principles for improving prompt interfaces in generative AI tools.

Methodology:

●Literature Review: Examine current research on prompt engineering, generative AI usability, and faceted search.

●User-Centered Design: Use participatory or iterative design methods to develop the interface, informed by interviews or surveys with users (e.g., content creators, educators, designers).

●Technical Implementation: Build a functional prototype using web technologies (HTML/CSS/JavaScript) and connect it to a generative AI model via API.

●Empirical Evaluation: Conduct controlled user studies comparing traditional and faceted prompt interfaces on metrics such as success rate, prompt quality, time to completion, and user satisfaction.

Expected Outcomes:

●Prototype Interface: A working faceted interface for prompt construction integrated with a generative AI backend.

●Usability Findings: Empirical evidence on the effectiveness and usability of structured prompt interfaces.

●Design Guidelines: Practical recommendations for designers of GenAI systems who want to offer more supportive and flexible user experiences.

Related Work:

●Russell-Rose, Tony, and Tyler Tate. Designing the search experience: The information architecture of discovery. Newnes, 2012.
