# Plan Documents

This folder stores time-sensitive implementation plans, investigation plans, and PRD-like planning notes.

Plans are not authoritative architecture, API, database, or product-state documentation. They may describe a proposed, partial, superseded, or already-completed direction. Agents and maintainers should treat files in this folder as historical planning context unless the user explicitly references a specific plan for the current task.

Use the top-level docs for maintained facts:

- `docs/ARCHITECTURE.md` for current system boundaries.
- `docs/API.md` for maintained API contracts.
- `docs/DATABASE.md` for current storage semantics.
- `docs/CANVAS.md` for current Canvas behavior.
- `docs/DECISIONS.md` for accepted decisions and supersession notes.

When adding a new plan, prefer a date or task-specific prefix in the filename so its time horizon is clear.
